## Result-level concerns

1. The pair-noq classical branch and deep-learning branch do not use perfectly identical row sets because the deep sequence TSVs restore 15 missing mate rows.
2. The deep-learning rerun path is currently blocked by a missing `dl_rnn.py` import dependency.
3. The repo contains both `reports/eval_final_all_t0p5.tsv` and `reports/final_run/eval_final_all_t0p5.tsv`; one should become canonical.
4. The fixed-epoch-25 CNN selection is documented by artifacts, but the rationale should be stated explicitly in the final release README.
