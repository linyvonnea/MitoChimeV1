# Example Data

This directory contains lightweight synthetic example inputs for smoke tests and
quick-start documentation.

- `example_pairs_R1.fastq` and `example_pairs_R2.fastq` are tiny paired-end FASTQ files.
- `example_pair_features.tsv` is a four-row feature table using the canonical
  publication schema.
- `example_pair_split.tsv` and `example_pair_seq.tsv` show the pair-aware tabular
  and sequence formats expected by the training and validation utilities.

These files are not the publication dataset and must not be used to reproduce
reported paper metrics.
