===== mitochime extract-features --help =====
usage: mitochime extract-features [-h] --bam BAM --out OUT --label LABEL
                                  [--k K] [--micro-window MICRO_WINDOW]

options:
  -h, --help            show this help message and exit
  --bam BAM             Coordinate-sorted BAM file.
  --out OUT             Output feature TSV.
  --label LABEL         Class label to assign (0, 1, or -1).
  --k K                 k-mer size used for composition features.
  --micro-window MICRO_WINDOW
                        Window size for microhomology extraction around the
                        inferred breakpoint.
