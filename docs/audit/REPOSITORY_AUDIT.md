# Repository Audit

## Overall condition

The repository contains a real, partially reproducible research workflow, but it currently mixes:

- active source code;
- legacy research scripts;
- duplicate source bundles;
- publication notebooks;
- manuscript and defense material;
- trained model artifacts;
- large generated datasets;
- filtered FASTQ outputs;
- SPAdes and GetOrganelle assembly outputs;
- logs, caches, and temporary files.

The highest-confidence canonical path is:

1. feature extraction and classical ML from `src/mitochime` plus `src/scripts/extract_features.py`;
2. deep-learning training from `src/mitochime/deep_learning`;
3. inference/filtering from `src/scripts/run_pipeline_gb.sh`, `run_pipeline_cnn.sh`, and `run_pipeline_rnnkmer.sh`;
4. assembly evaluation from `src/scripts/run_spades.sh` and `reports/final_*` / `data/assemblies_spades/final_run`.

Major audit findings:

- `src/mitochime/cli.py` and the top-level `Makefile` are stubs and do not drive the real paper workflow.
- `src/mitochime/deep_learning/train_deep.py` imports `from .dl_rnn import RNNClassifier`, but `dl_rnn.py` is missing; this blocks rerunning deep-training modes without cleanup.
- `data/processed/all_reads.tsv` contains 39,983 rows and 19,999 base `read_id` values; 15 base IDs appear only once in the feature tables.
- The sequence datasets (`PAIR_*_seq_L150.tsv` and `PAIR_*_seq_L300.tsv`) restore full paired rows from FASTQ, so the deep-learning datasets are not perfectly row-identical to the feature-table datasets.
- `models_pair_noq_tuned/` and `models_PAIR_noq_tuned/` are duplicate directories with identical contents.
- Several notebooks and report families exist in both earlier and later forms; final publication selection still needs researcher confirmation.

## Classification summary

- `REQUIRED`: core scripts and datasets for the paper workflow exist and are identifiable.
- `REQUIRED_WITH_CLEANUP`: likely core, but currently blocked by stubs, duplication, or environment/documentation issues.
- `OPTIONAL_ANALYSIS`: useful side-analysis or supplementary material, but not required for the main publication story.
- `GENERATED_OUTPUT`: rerunnable or derivable artifacts that should be curated, archived, or externally hosted.
- `DUPLICATE`: same or overlapping content exists elsewhere in the repository.
- `OBSOLETE` / `DRAFT`: old or incomplete material not suited for the final cleaned repository.
