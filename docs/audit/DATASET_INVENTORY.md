## Dataset-level observations

- `data/processed/all_reads.tsv` contains 19,999 unique base IDs; 15 IDs appear only once in the feature tables.
- `PAIR_train_seq_L150.tsv` and `PAIR_test_seq_L150.tsv` restore full mate rows from FASTQ and therefore contain 31,998 and 8,000 rows respectively, not 31,986 and 7,997.
- The classical pair-noq branch and deep-learning branch therefore share the same pair split but not perfectly identical row-level training/evaluation tables.
